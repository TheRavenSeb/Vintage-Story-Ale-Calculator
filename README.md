# Vintage Story Alcohol Calculator

A small, local-first calculator for planning fermented and distilled alcohol in Vintage Story.

Choose a recipe and desired output to see the required fruit, honeycombs, flour, water, barrels, fermentation time, and optional distillation output. The site is plain HTML, CSS, and JavaScript and deploys directly to GitHub Pages.

## Data source

Game values are based on the [Vintage Story Wiki Alcohol brewing page](https://wiki.vintagestory.at/Alcohol_brewing), verified for Vintage Story 1.21.5. Fruit and honey input assumptions use the [Fruitpress page](https://wiki.vintagestory.at/Fruitpress).

The wiki content is available under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This is an independent fan tool and is not affiliated with Anego Studios or Vintage Story.

## Development

There is no build step or dependency installation. Serve this folder with any local static-file server and open the page in a browser. Check the browser console and test fruit, honey, and grain recipes after changing calculations.
